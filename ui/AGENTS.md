# UI surface routing

Read `registry.yaml` before planning, creating, replacing, or retiring a human-facing
surface. Patch the registered candidate by default and use the shared `ui` skill for
representation, implementation, and browser verification.

The topic-map generator and template remain in `tools/` to fit the existing data pipeline.
Its quote-bearing output and screenshots belong only under the gitignored
`private/xconv/` tree. Never commit source conversations, positions, exact quotes, or the
generated page.

For material UI changes, retain a schema-valid `ui-learning-receipt/v1` in the registered
receipts path. Candidate observations are not policy; only Brian can promote them.
