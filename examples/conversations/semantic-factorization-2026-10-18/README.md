## Current frontier

The conversation has surfaced a broader reusable pattern: start from a goal, search systematically for prior art across disciplines, synthesize only where needed, validate against concrete cases, and develop new material only for a demonstrated gap. The new `research-protocol.md` records a proposed method for doing that. It is a combination of established methodological components, not a claim that one published standard prescribes this exact combination.

For the representation-framework case, find the closest existing formal framework that can account for multiple forms of representation—including descriptive models, formal theories, mappings/interpretations, and executable or proof-producing systems—without assuming that one universally accepted canonical factorization already exists.

The fit review distinguishes this research question from Inquiry Graph's own schema. A single conversation can reveal a candidate representational gap but cannot authorize a shared schema change.
